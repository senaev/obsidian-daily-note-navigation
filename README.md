# Daily Note Navigation

Adds a bar at the top of daily notes to quickly navigate between them.

![daily note navbar](https://github.com/user-attachments/assets/c51038e7-3c04-4ed0-976d-9d4145e9c98d)

## Getting Started

Replaces the view header in daily notes files with a navbar. The normal view header is still displayed for other files, and you can still rename daily note files both in the tab bar and in the file explorer.

## Inspiration

Inspired by and partly copied from https://github.com/karstenpedersen/obsidian-daily-note-navbar

## Installation

1.  Open Settings.
2.  Go to "Community Plugins".
3.  Enable community plugins by pressing "Turn on community plugins".
4.  Click "Browse" to browse available community plugins.
5.  Search for "Daily Note Navigation".
6.  Click "Install" and enable the plugin.
7.  Close the community plugins window.
